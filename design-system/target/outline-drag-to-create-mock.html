Drag a chip: zones appear between chapters; drop on a heading to join that chapter, drop in a zone to start a new one.

What the mock encodes

  • Zones exist only during a drag. They animate open (0 → 30px) on dragstart and vanish on dragend, so the resting outline is untouched — the point of choosing C over a permanent split affordance.
  • Two drop meanings, one gesture. Chapter heading highlights blue = "join this chapter" (already implemented). Zone highlights green = "become a new chapter here".
  • Illegal zones simply do not appear. A zone is only offered where the DAG lets that block land (same gap-range computation the reorder drag already uses); in the mock, try dragging Analysis subset above First 50 rows — that zone stays hidden.
  • The new chapter is born named and in rename mode ("New chapter", title focused) — not modelled here, but part of the operation.
Consequence worth naming: a chapter created this way starts with exactly one block. Growing it is the existing gesture (drag more chips onto its heading), so the pair composes — but if authors routinely want to split a long run in half, the boundary "split here" pill (variant A) remains the better primitive and can be added later without conflict.

Mock only — no server, no persistence; the real thing detaches the block from its old stack and creates the new one in a single update payload. Decision record for blockr.outline; follows outline-new-section-proposals.html.
