Outline toolbar — the render action's label

We picked the split button (A): neutral format picker fused to a green action. The open question is the right half's label. "Render" is a bit of jargon for what is really "produce the document" — so how little can it say and still be clear? All at the shipped control height, on the real panel.

1 — Download icon only your suggestion

Format plus a bare download arrow, no word. Tightest, and the format already tells you what you get. The one risk: a download arrow usually means "save something that already exists", but this button runs a render first (quarto churns for a few seconds). Icon-only slightly undersells that work is about to happen — mitigated by a tooltip, but a tooltip is not visible up front.

Hover the icon to see the tooltip stand in for the missing word.

2 — Icon + "Download" decided — implemented

The outcome as the verb, not the mechanism. "Download" says what you walk away with (a file), which is what a user cares about; "render" is the internal step. Same width class as "Render", clearer to someone who does not know the quarto pipeline.

3 — Icon + "Render" current

What ships today. Accurate — it does render — but leans on a word an end user may not map to "make me the document".

Decided 2026-07-21: split button (A) with label 2 — icon + "Download", implemented in blockr.outline. The format picker (neutral) fused to the green action, one bordered pill divided by a hairline. Both groups on the toolbar sit at one control height and one centre line — the switcher is a shinyWidgets input, so it arrives in a form-group with a 16px bottom margin that, under align-items:center, lifted it 8px above the render group; zeroing that margin lines them up. Original recommendation, for the record:

2 — icon + "Download". Your instinct to drop "Render" is right; it is the internal step, not the outcome. But go to "Download" rather than icon-only: the word costs a few pixels and buys the one thing a bare download arrow loses — the signal that clicking does something (and produces a file), not just saves one already sitting there. If the toolbar ever gets tight, 1 is the fallback, with the format label carrying the meaning and a tooltip on the icon.
