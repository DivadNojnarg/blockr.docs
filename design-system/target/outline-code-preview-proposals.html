Outline code preview — surface and copy affordance

The R script and Document views put a grey rounded box inside the panel's own white card. Two frames, nested, for one piece of content. These are four ways to collapse that to one surface and move copy onto the code itself.

Where we are now problem

The code sits in .blockr-otl-raw — grey fill, 6px radius, 12px padding — which is itself inside the panel's padded white card. The copy button lives up in the toolbar next to Render, far from the thing it copies, and reads as a document-level action rather than a code action.

A — Flush surface, copy on hover lightest

Drop the grey fill and the radius entirely. Code sits directly on the panel, which is already a card. Copy is a ghost button in the top-right that fades in on hover, the way GitHub does it on a README code block. Nothing frames the code but the panel itself.

B — GitHub file header decided (header kept)

What GitHub actually does for a file: one bordered region, a slim header strip naming the file with the actions on the right, then the code. The header replaces the nesting — there is still only one frame, and it earns its keep by saying what you are looking at, which the two views currently never state.

# Data prep

Everything the analysis consumes: the raw data, the species restriction
and the derived ratio.

```{r}
#| label: tbl-data
#| tbl-cap: "Iris data"
data <- datasets::iris
data
```

Drop *virginica*: the two remaining species overlap.

```{r}
#| label: tbl-filt
filt <- dplyr::filter(data, Species %in% c("setosa", "versicolor"))
filt
```

Derive the sepal **ratio**.

```{r}
#| label: tbl-mut
mut <- dplyr::mutate(filt, ratio = Sepal.Length/Sepal.Width)
mut
```

Decided 2026-07-20: C plus B's header, implemented in blockr.outline. The tinted full-bleed surface from C, carrying C's contrast, under B's file header naming report.R / report.qmd with copy in it. The header is position: sticky, so D's benefit comes along for free. The toolbar was restyled to the segmented control and small neutral buttons drawn here, and its copy button now hides itself whenever the file header is on screen (keyed off the header existing, not off the view name, so the two cannot disagree). One trap worth recording: downlit's pre.chroma paints its own background and inherits a bootstrap border, so it reproduced the nested box until both were cleared — the surface owns the tint, the wrapper only carries token colors.

Original recommendation, kept for the record:

B, with D's sticky behaviour folded in. It is the one that is literally GitHub, it kills the nesting, and the filename strip answers a question the current views leave open — whether you are looking at report.R or report.qmd, which right now you can only infer from which segment is highlighted. Making the header position: sticky keeps copy reachable in a long document for free.

One knock-on either way: the toolbar's copy button goes away in these two views. The Outline view has no visible code surface, so it keeps its toolbar copy button (it copies the whole script from the hidden buffer).
